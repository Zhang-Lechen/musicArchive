# 统一验收清单

本清单对应 PLAN 阶段 0—11，日期为 2026-11-04。先完成自动化检查，再按下列路径手工验收。

## 启动与自动化

```sh
npm install
npm run lint
npm run typecheck
npm run test
npm run build
npm run test:e2e
npm run format:check
npm run catalog:check
npm run dev
```

E2E 默认需要本机 Edge Chromium，也可按 README 切换 Playwright Chromium。E2E 用例是隔离档案，不操作个人浏览器数据。生产离线检查请使用 `npm run build` 后 `npm run preview`，不使用开发模式。

## 产品验收

- [ ] 首页显示真实作曲家、生卒年、音乐时期、已听过 / 当前可统计作品数；有目录不完整提示。
- [ ] 输入“莫扎特”、Mozart 或变音姓名能筛选作曲家，停顿后继续输入时焦点不丢失；时期筛选可组合。
- [ ] 中文输入法拼音组字期间不切页、不把中间拼音提交搜索；确认汉字后搜索。Enter 选字不误提交，浏览器返回、清空与直接打开中文查询仍正常。
- [ ] 进入莫扎特，搜索 `K551`、`K. 551`、`KV 551`、`朱庇特` 均找到第41交响曲。
- [ ] 编号按主号自然顺序排列，K.9 在 K.10 前；名称排序和听过/未听过、体裁筛选可组合；无结果有明确提示。
- [ ] 未听过作品有“○ 未听过”和聆听按钮；点击按钮仅快速记录，不误开弹窗。
- [ ] 快速聆听新增本地今天，只写一次；图标、文字、表面和进度同步改变，可立即撤销。
- [ ] 已听过卡片直接显示最近聆听日期，保留年/月/日精度；无已知日期时显示日期不详。修改、删除、撤销或恢复备份后，卡片日期即时更新，未听过作品不显示此行。
- [ ] 弹窗可修改为 `2019-06-15`，显示 `2019年6月15日`；可另添加精度为年份的 `2019`，显示 `2019年`，不会伪造为 1 月 1 日。
- [ ] 年月精度按实际月保存；无效日历日期、未来日期、同精度重复日期被拒绝。
- [ ] 可直接标记“已听过（日期不详）”，日期列表为空仍是已听过。
- [ ] 删除最后一条日期仍保持已听过；恢复未听过要确认并清空全部日期，撤销可恢复。
- [ ] 弹窗 ESC、关闭按钮、遮罩关闭正常；未保存修改会提示；焦点被限制在对话框内，关闭后回到打开按钮。
- [ ] 可跨页选择多个作品，批量记录今天或日期不详，支持撤销；全部成功或全部回滚。
- [ ] 两个标签页打开同作品，在一页写入后另一页状态和进度更新，无需刷新。
- [ ] 刷新页面、关闭并重新启动同一浏览器档案后，聆听记录仍保留。
- [ ] 导出 UTF-8 JSON，文件名包含本地日期；含目录、进度、日期、别名、映射和必要元数据。
- [ ] 在另一个浏览器档案导入备份，先看到数量、版本、时间与替换提示；确认后恢复 2019 年记录和进度。
- [ ] 错误 JSON、未来格式版本、无效引用、矛盾状态、循环层级和非法日期不能污染原数据。
- [ ] 手动补录同作曲家同编号时拒绝重复；可以填写无编号、别号、存疑、片段、佚失、作品集、乐章和上级作品。
- [ ] 子作品/乐章/作品集/佚失条目不能写入独立进度；默认不推断整部作品与乐章的听过关系。
- [ ] 作品编号及原文可读名称总是可见；缺少编号明确标“未编号”，不使用数字假条目。
- [ ] 目录导入有独立预览和确认；反复导入同一文件不增加重复作品，不清除个人记录；歧义拒绝并提示复核。
- [ ] 页面每页最多 36 张作品卡片，搜索末条、翻页和窄屏布局可用；320px 不横向溢出。
- [ ] 生产模式先联网打开至“离线已就绪”，断网刷新、查询、写记录及再次刷新均正常。

## 明确保留的限制

- 全部扩展目录均为 partial；15,001 项复核任务尚待持续音乐学审校。这是透明的数据覆盖限制，不标为专业人工审校完成。
- 来源没有明确标注的父子粒度、复杂目录版本关系和作品归属不自动推断。核心 12 部样本有交叉核对链接，仍不构成莫扎特全集。
- 本地浏览器存储有丢失风险，无云备份，必须自行导出。
- 本次没有外部部署；生产站点需配置 SPA 回退，HTTPS 才能提供离线能力（localhost 例外）。
- 当前 E2E 是 Windows Edge Chromium。Firefox、Safari、真实移动设备需要后续兼容验收。
- 开发依赖有已记录的中危审计告警及弃用提示；生产依赖审计为 0，详情见决策记录。
- 未来原生移动端、云同步、账户、播放、录音版本等未纳入本次实现。
