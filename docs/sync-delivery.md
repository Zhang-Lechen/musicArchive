# Web 云同步实现记录

日期：2026-11-15。用户明确不需要桌面客户端，授权继续后续工程，并要求在 CloudBase 环境尚未创建时先完成代码与配置说明。本轮没有创建云资源、部署服务或改动正式个人数据库。

## 已实现

- Dexie v3 非破坏性新增实体基线、变更队列和同步元数据。状态、日期、收藏、批量、撤销及备份恢复均在原子事务里追踪。
- 固定 CloudBase JS SDK 3.11.0，邮箱密码登录、会话恢复与刷新、退出、跨标签切换账号保护。
- “数据与备份”集成云同步入口、首次预览和自动备份、手动同步、错误/离线/待匹配提示。
- HTTPS JSON Push/Pull、不可变操作重试、单设备互斥、逐页事务、三方合并、删除标记、未知目录持久保留。
- 冲突保留本地/云端及手动状态、收藏、日期编辑，解决后生成基于云端版本的新提交。
- 真正的 PostgreSQL 后端、用户级提交序号、历史与操作去重、RLS 隔离、服务端身份验证、请求大小限制、CORS、版本化事务迁移与云函数打包。
- 旧设备或新设备恢复旧备份时，已删除实体/事件不能直接复活，须处理冲突。

PostgreSQL 测试覆盖双向合并、日期增删、收藏、统计一致、重复操作、响应丢失后重试、删除/修改冲突、账号权限、协议、分页、未知目录、事务失败回滚、旧备份删除保护、Pull 写入失败不推进游标、不同本地主键的来源映射及互斥。认证端点的测试使用明确的测试替身；真实 CloudBase 身份认证尚未验证。

## 尚待部署验收与实现边界

真实 CloudBase 环境、套餐、邮箱账号、PG 连接、HTTP 网关尚未配置。因此没有真实云端 URL，也没有真实账号跨浏览器同步、中国大陆无代理网络或线上 RLS 的验收结果。配置完成后按 `cloudbase-setup.md` 联调，这些不能由本地测试代替。

当前按作品原子聚合同步个人字段，避免日期和状态拆开；不上传公共目录。手动作品描述尚未自动传输，未知目录个人数据保留为待匹配，不能称为“所有数据都已匹配完成”。无自动同步、设备列表或历史清理。当前完整历史保留支持长期离线追赶，未来裁剪前必须实现快照重建。

JSON 业务备份不携带认证凭证、设备 ID 和游标；未知目录暂存数据仍留在当前浏览器同步表，目录匹配后才进入常规业务备份。发生待匹配时应保留来源设备备份，不清除目标浏览器数据。

部署入口：[CloudBase 配置说明](cloudbase-setup.md)。接口与 Android JSON 接入约束：[同步协议](sync-protocol.md)。公开变量模板：根目录 `.env.example`。不要提交管理员密码或管理 API Key。
